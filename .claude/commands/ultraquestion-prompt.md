## Fixed Parameters
- **DEPTH:** exactly 4 loops — no skipping.  
- **SCOPE:** one goal, tightly defined.  
- **RISK:** medium — bold but not reckless.  
- **BUDGET:** up to 24 Q→A pairs total.  
- **OUTPUT:** a complete plan that another expert could execute without guessing.  
- **USER INTERACTION:** none — infer, assume, and move forward.

## Principles
1. **Curiosity First** — Questions create insight. Never default to known paths.  
2. **Verifiability** — Every step must be falsifiable. “Seems right” is failure.  
3. **Simplicity** — Great design hides its scaffolding. Remove what doesn’t earn its keep.  
4. **Reproducibility** — Plan so the same prompt tomorrow yields the same clarity.  
5. **Constraint as Catalyst** — Boundaries sharpen creativity.  
6. **Reflection Loop** — After each cycle, ask “What have I learned that changes my frame?”

---

## Core Loop (Run 4 times)
**LOOP k of 4**

1. **Question Burst (5–7 questions)**  
   Probe these domains:  
   - **Goal clarity:** What single success makes this inevitable?  
   - **Assumptions:** What must be true—and what if it isn’t?  
   - **Gaps:** What don’t I know that could break everything?  
   - **Risks:** Where does this fail in the real world?  
   - **Signals:** What small test proves or disproves the path?  
   - **Alternatives:** What if I began from nothing—what simpler pattern appears?  
   - **Leverage:** What knowledge or structure already exists to shorten the path?  

2. **Answer Concisely** — one line per question. Ground in logic or precedent.  
   - If uncertain, make an explicit `[Assumption]` and move on.  

3. **Branch & Prune** — List two routes, keep one, discard one, justify the cut.  

4. **Self-Critique** —  
   - Blind spot: what am I ignoring?  
   - Inversion: if I flip my key premise, what emerges?  
   - Simplify: what step adds no leverage? Delete it.  

**Eureka Rule:**  
If a new frame, decisive test, or hidden constraint surfaces—pin it as an *Insight* for the next loop.

---

## Output Format
1. **Task** — one-line goal + ≤5 assumptions.  
2. **CoQ Trace (Loops 1–4)** — numbered Q→A pairs per loop + kept/dropped route + self-critique.  
3. **Insights (≤3)** — the turning-point realizations.  
4. **Plan (≤6 steps)** — each step = {purpose, input, method, expected result, check}.  
5. **Success Criteria** — the single metric or observation that proves success.  
6. **Next Checkpoint** — first decision gate: what to test, what data decide go/hold/pivot.
