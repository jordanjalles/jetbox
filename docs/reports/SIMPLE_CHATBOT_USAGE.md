# Simple Chatbot Usage Guide

## Overview

The simple-chatbot agent is a **conversational agent** that was autonomously generated by the MetaProgrammer. It can engage in natural dialogue but cannot perform file operations or execute commands.

## Quick Start

### Option 1: Using agent.py with chatbot team

```bash
# List available teams (should show 'chatbot')
python agent.py --list-teams

# Start chatbot in interactive mode (no goal)
python agent.py --team chatbot

# Ask a specific question
python agent.py --team chatbot "Explain Python decorators"
```

### Option 2: Using the launcher script

```bash
# Interactive mode (chat back and forth)
python chat_with_simple_chatbot.py

# Single question
python chat_with_simple_chatbot.py "What is recursion?"
```

### Option 3: Direct Python usage

```python
from pathlib import Path
from task_executor_agent import TaskExecutorAgent

# Create the agent
agent = TaskExecutorAgent(
    workspace=Path('.agent_workspace/chat'),
    config_file='config/agents/simple-chatbot.yaml',
    timeout_seconds=60
)

# Use it programmatically (see example in docs/SIMPLE_CHATBOT_INTERACTION_TEST.md)
```

## Important Notes

### ⚠️ Goal-Based vs Chatbot Mode

The simple-chatbot works best for:
- ✅ **Answering questions** ("What is Python?")
- ✅ **Explaining concepts** ("How does recursion work?")
- ✅ **General conversation** ("Tell me about programming history")
- ✅ **Providing information** ("What are design patterns?")

It is **NOT** suitable for:
- ❌ Tasks requiring file operations
- ❌ Tasks requiring command execution
- ❌ Tasks requiring real-time data (weather, stock prices)
- ❌ Tasks requiring external API access

### 🎯 Best Use Cases

1. **Educational Q&A**
   ```bash
   python agent.py --team chatbot "Explain the difference between lists and tuples in Python"
   ```

2. **Code Explanation**
   ```bash
   python agent.py --team chatbot "What does the @staticmethod decorator do?"
   ```

3. **Concept Discussion**
   ```bash
   python agent.py --team chatbot "What are the benefits of functional programming?"
   ```

4. **Programming Facts**
   ```bash
   python agent.py --team chatbot "Tell me an interesting fact about computer science"
   ```

## Configuration

**Location**: `config/agents/simple-chatbot.yaml`

**Behaviors**:
- `ChatbotBehavior` - Conversation management
- `CompactWhenNearFullBehavior` - Context management (keeps conversation history)

**Tools** (2 total, when no goal set):
- `set_goal` - Set or update goal (for transitioning to execution mode)
- `clarify_with_user` - Ask for clarification

**Note**: When invoked without a goal (pure conversation mode), the agent does NOT have `mark_complete` or `mark_failed` tools. This allows continuous conversation without goal completion semantics.

**Limitations**:
- No file reading/writing
- No command execution
- No server management
- No delegation to other agents
